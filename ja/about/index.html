  • 活動領域 : 低レイヤー（物理制御・KVM・インフラ）からWebアプリケーション開発、大規模プロジェクトのファシリテーション・組織的教育までカバー。

技術サマリー

【物理制御からDB、大規模PJのファシリテーションまでを完遂するアーキテクト】

  • 圧倒的な問題解決能力とリスク管理:
    サービス急成長期のDB負荷危機に対し、迅速なPoCを経てオンラインでのテーブルタイプ変更を断行。リリース直前の設計不備に対しても、事業インパクトを優先した現実的な改善ロードマップを提示しプロジェクトを成功に導く。
  • カオスな現場を整理するファシリテーション:
    ステークホルダー間の調整が難航する会議において、ホワイトボードを用いた可視化により課題の本質を抽出。複雑な調整をシンプルに解決し、専門家からも高い評価を獲得。
  • アーキテクチャ設計とパフォーマンス最適化:
    理論に留まらず、Seasar2 + JAX-RS (Jersey) による高パフォーマンスなREST APIの構築や、C++によるビデオフィルタ実装など、低レイヤーからWebまで広範囲をカバー。
  • 実戦型教育のスペシャリスト:
    アクティブリコール重視の独自カリキュラムにより、累計数百名のエンジニアを現場へ輩出。
  • FinOps & DevOps:
    AWS CUR可視化によるコスト最適化、および自作KVM基盤上へのDevOps環境（GitLab-CI/Sentry等）の構築。

主な経歴

  • 現在 : 都内企業にて、アプリケーション開発およびエンジニアリンググループのマネジメント、社内勉強会・仮想化基盤の啓蒙/主導等に従事。
  • 過去の主な参画領域 :
    • 大手自動車メーカー向け開発・コンサル: 独自フレームワークのセキュリティ分析からの刷新提案、高級車ブランド向けシミュレーター開発の完遂。
    • 自営業 / フリーランス: 大規模な動画配信プラットフォームの更改、大手小売業ECサイトの刷新など、Javaアーキテクトや、DBエンジニアとして各種プロジェクトに参画。
    • 外資系R&D: Windows サーバグループのR&D（日本拠点）、ネットワークコンポーネントや相互運用パッケージのQA・検証を担当。
    • 黎明期からのSI・Webオープン系開発: 汎用機オペレータからC++による端末アプリ開発、大規模なJ2EE/Java案件のテックリード・プロジェクトマネジメントを多数経験。
