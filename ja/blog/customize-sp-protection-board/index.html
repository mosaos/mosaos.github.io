スピーカー保護ボード

Aliexpress を眺めていたら、オーディオスピーカー保護ボードなるものを発見してポチったのだ。

AC 12-16V となっているもので、組み立て済みではなくてキット(組み立て済みも売ってる)。
似たようなものは結構売っていたのだが、そこそこレビューもついているものを購入した ( Aliexpress Link を参照 ) 。

２個買って無事に２個到着。

自作デジタルアンプがあるので、これに組み込もうと思ってたのだが、上でも書いたように AC(交流) 12V-16V 用。
そのままでは使えないだろうとは思っていて改造前提で購入。

基板は以下。

基板、及び、完成写真からは、まず以下のことが判った。

  • AC入力を整流(DCに変換)するために ブリッジダイオード がある ( 基板の A1 ) デジタルアンプなどは DC(直流) なので不要
  • ブリッジダイオードの後に 三端子レギュレータ がある ( 基板の L7812CV )
    これでAC12-16Vから直流にしたものを12Vにしている。DC12V 以下で動作するデジタルアンプであれば不要
    ※ ACV × √2 が理論値なので AC12V -> 約DC17V。ダイオードの電圧降下もあるので、実際は 15V程度になる。

なので、これらはスキップしてあげれば直流で動作するアンプでも動作するはずと予想。

※ ブリッジダイオード前に DC12V を入れる事も可能なのだが、ブリッジダイオード+三端子レギュレータによる電圧降下によって、回路部分の電圧は9V程度になる -> リレーが安定動作しないになる可能性が高い。

あと、手持ちの PAM8406 で動作させようと DC5V 化も行うために、以下も行うことにした。

  • リレーの変更
    電圧が DC12V -> DC5V になるので、リレーの変更が必要。SRD-12VDC-SL-C が付いているので SRD-05VDC-SL-C に交換。 SRD-05VDC-SL-C 5PIN, 5PCS を購入 ( Aliexpress Link を参照 )
  • 5V リレーが動作するように抵抗値を変更
    回路には DC12V ではなくて DC5V が入ることになる。5Vのリレーは上記リレーの製品サイトを見ても判るのだが、必要な電流値 ( コイル電流 ) は以下。
    • 5V : 72 mA
    • 12V : 30mA 電圧も 12V -> 5V に下がっているので、抵抗がそのままだとリレーは全く反応しない可能性が高い。

改造

上記改造を施した基板の写真を最初に示す。

この時点では改造箇所は３か所 (section1 - section3)

Section 1

  • A1 及び L7812CV は取り付けない。
  • 元々は AC 部分に取り付けるターミナルは A1 の出力部分 ( +, - が印刷されている ) に取り付けた。
  • 基板パターンを見ると判るが、これだけだと回路に + が入らないので、L7812CV の両端をジャンパワイヤで短絡する。真ん中にあるランドに触れてショートしないようにする事。私はリード線の切れ端とかではなくて、被覆線を用いた。

これで、ターミナルに入れたDCがそのまま回路に入るようになる。

Section 2

上で書いた 5V リレーが動作するように抵抗値を変更 部分。基板上は 100K になっている。AIに質問した際に、「ここをショートすればリレーが反応する」とか言ってたのだが、トランジスタが死ぬ ので厳禁ｗ。

Section 3

リレーを SRD-12VDC-SL-C から SRD-05VDC-SL-C に交換。

Section 4

この時点では気づいてない。( 後述 )

動作確認

100円ショップで買ったUSBケーブル(断線したりしたやつ)を改造したケーブルを持っているのだが、これをターミナルに接続して、モバイルバッテリーに接続して動作確認した。

この時点で、section 2 に関して以下のような事を実施。

  1. 最初 10K で動作確認
    1秒未満でリレーが「カチッ」と動作
  2. 47K に変更。動作する場合もあるが不安定。遅延は2秒ちょっとに伸びる。
  3. 33K にしたかったが、手持ちがなかったので、68Kを2本並列に(=34K)
    遅延1秒ちょい位で、動作も安定したのでこれにした。

DC5V 入力でリレーが反応する事まで確認。

アンプを接続

PAM8406 を接続して実際に動作するか確認。

この基板、裏のパターンを確認するとすぐに判るのだが、スピーカーの GND は共通 になっている。 PAM8406 を含めたデジタルアンプの多くは BTL 接続で、シングルエンドのアンプとは異なり、GND は L-/R- ( + の逆位相の電圧がかかっている ) であって、GNDではない。短絡してはいけない のだ。

アンプからのマイナスの出力 ( L-/R- ) をこの基板に繋ぐと最悪アンプが壊れるので、絶対に接続していはいけない。
だったらどうする？って話かもだが、

  • L+/R+ はこの基板の L/R ( 基板裏で短絡してない方 ) に接続する
  • L-/R- はこの基板は通さずにSPに直結する

にすればよい。

上記短絡問題も気を付けつつ PAM8406 を接続してみたのだが、見事に動作しなかったｗ

実はこの基板は遅延リレーだけではなく、DC プロテクトとも書いてある通り ( 後から改めて気づいたw )、スピーカーに流れる DC 検知もして DC漏れしている場合には、リレーを動作させないという保護回路もついているのだ。

お安い回路の割には結構しっかりしていた。

元々基板パターンからして BTL 対応ではない = シングルエンド用であり、この場合にはこの DC プロテクトがあっても問題はないのだが、BTL の場合には + / - ともに電圧がかかっているので、DC プロテクトが反応してしまい、リレーが ON にならないという状態になっていたというのが、動作しなかった原因。

※ VDD = 5V なら OUT+/OUT- 共に約2.5V(弱)程度の DC が無信号時でもかかっている。

DCプロテクトに繋がっている抵抗を ( section4 ) を変更して PAM8406 の 2.5V が発生しても DC プロテクトが動作しないようにする方法もあるとは思うのだが、これに関しては面倒だった ( そもそもポップノイズ対策の遅延リレーが欲しくて買った ) のもあって、section4 部分の抵抗を外す事で対応した。
DC プロテクトは効かなくなるが、起動時のポップノイズ対策で十分であれば、この改造で要件は満たせる。

最終的には以下のようなアンプになった。

  • PAM8406
  • Bluetooth(v5)対応
    対応基板は安く売ってる
  • 今回の スピーカー保護基板
    上記はいずれも USB-C端子から 5V 供給 ( 並列に分岐 )
  • 入力は3.5mmステレオフォン端子からとBTの 2入力対応
    切り替えは２回路２接点のトグルで切り替え ( 音声入力の GND は切り替え無しで共通で問題なし )
  • スピーカーも3.5mmフォンジャックで接続
    タカチの YM-10(YM10-3-7) を使ってコンパクトにしたので、スピーカーターミナルだと厳しかった。あとシルバーをフロントにしたいという YMシリーズの普通の使い方とは違うやり方してるのもある。

元々、子供が AG03 持ってるのだが、手持ちのパッシブSPがならせなかったので作ったアンプ。
BTは要件ではなかったのだが、単体で動作させることも考えた場合、スマホ等からBT経由でならせる方が汎用性がある。

写真は以下。基板の固定は 100円ショップなどで手に入る YAMORI GRIP ( 超強力両面ゲルテープ ) を使った。端子部分がケースに触れないようにマスキングテープで保護した上で。

※ YAMORI GRIP 自体結構厚みがある ( 2mm ) ので、それだけでも問題ない可能性が高いが、金属ケースを使う場合には念のためある程度の対策はしておいた方が良いと思う。

他のデジタルアンプにも

TA2020 も持っている ( NFJ 基板ベース ) ので、そのうち DC12V のままのバージョンも個人的には作る可能性は高い。

この場合、Section 1, Section 4 のみ対応すれば OK。

これ以外にも PAM8403 等は PAM8406 よりもポップノイズが煩いと言われているので、デジタルアンプで比較的低コストでポップノイズ対策をしたい場合には、この記事の対応が有効かも。
