kernel update されない Rocky Linux

CVE-2026-98432 kernel: ipv4: free inet_opt and ireq_opt after an RCU grace period

の対応を行っている途中で一台の Rocky Linux でカーネルが更新されないという状況に遭遇した。

環境

OS : Rocky Linux 9.8

実はこのホスト(KVMゲスト) は Rocky 8 から 9 にアップグレードしたものである。

手順

普通に以下でアップデートできると思ったのだが...

sudo dnf update
メタデータの期限切れの最終確認: 0:04:52 前の 2026年11月05日 12時07分45秒 に実施しました。
依存関係が解決しました。
行うべきことはありません。
完了しました!

rpm -qa で確認するも、何も出力されない。
※ 他のパッケージは検索できる。

rpm -qa | grep kernel

kernel つけて再度実行。

sudo dnf update kernel
メタデータの期限切れの最終確認: 0:05:28 前の 2026年11月05日 12時07分45秒 に実施しました。
パッケージ kernel は利用可能ですが、インストールされていません。
一致した引数がありません: kernel
エラー: アップグレード対象のパッケージがありません。

kernel パッケージ自体入ってない ってどういう事？

調べた事

※ ちなみに AI に聞いてみたところ dnf-automatic がーと検討違いのうざい回答を複数AIから得られた.. クソうざかったw

結論

どうやら kernel パッケージがいつの間にか消えたようだ。

理由は不明
調査 ( 後述 ) したが結局判らず。Rocky8 -> Rocky9 へのマイグレーション等も影響して何かが起きたのかもしれない。

パッケージとしてインストールされていないので dnf update しても更新されなかったのだ。

とりあえず、仕方がないので、パッケージをインストールする事にするが、普通に dnf install kernel した場合には最新版がインストールされてしまうため、その後に dnf update で更新されるかが完全には確認できない。ので以下を行う事にした。

  • 古いバージョンの kernel を敢えてインストールする
  • インストールが確認できた後に dnf update して更新されるか確認する
